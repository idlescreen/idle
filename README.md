# idlescreen/idlescreen

Central governance, audit, and scripts for the IdleScreen org.

Process kit at root — `DESIGN.md` (vision), `PM.md` (status dashboard),
`SPRINT.md` (sprint planning), `OODA.md` (rotation + bundled swarm ops),
`PROBE.md` (adversarial), `RULES.md` (axioms). Load these together;
they're a kit.

Per-finding audit methodology is in `PROBE.md` (adversarial); resolution
records live in commit messages and `PM.md` residuals table. Hygiene +
chaos + publish-gate scripts in `scripts/`.

Product code lives in separate repos under the `idlescreen/` GitHub org,
not here. This repo tracks how we work, not what we ship.
